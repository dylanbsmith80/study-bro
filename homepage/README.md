# Study Bro Homepage

Public marketing site for Study Bro. This folder is deployed as its own Vercel project with `homepage` configured as the Root Directory.

- `index.html`: page structure and copy
- `styles.css`: responsive visual system
- `script.js`: lightweight reveal behavior
- `assets/`: homepage-only brand assets

The `data-app-link` anchors point to the Study Bro application. Update those URLs after the authenticated platform deployment receives its production domain.
